This program writes a one-line gadget roast to `entry.txt` in the output directory, then reads the file back to verify the text and bytes were written exactly. The roast lands because a doorbell promises advance warning, and the punchline reframes its lateness as a curated montage of the slowest decisions.

## How it runs

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
